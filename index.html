Everything a young learner needs, in one app

Learn, practise and get assessed — designed with schools, safe for kids, and it keeps working when the internet doesn't.

AI Explorers course

A free, interactive first course on Artificial Intelligence for Class 4–5. Short picture-style cards, a sorting activity and a quiz in every lesson.

Coding challenges

A HackerRank-style board with search and filters. Solve problems in a real code editor with VS Code-like suggestions, then press Run code to check against sample tests.

Tests & assignments

Multiple-choice, written and coding questions from your teachers. Submit in the app and see released scores and feedback in Results.

Works offline

Python runs inside the app (no internet needed). Drafts save automatically and submissions sync when you're back online.

Progress & badges

A progress ring for the course, a badge for every module, and a solved/points tracker for challenges.

Safe by design

Students only see their own work, teachers only their classes, and every school's data is isolated in the database.

Installing for the first time?

The app is safe. It isn't signed with a paid certificate yet, so your computer may ask you to confirm once.

Windows

If you see “Windows protected your PC”, click More info → Run anyway.

macOS

Open the .dmg and drag the app to Applications. If it's blocked: System Settings → Privacy & Security → Open Anyway. If it says “damaged”, run in Terminal:
xattr -cr "/Applications/L_Platform Student.app"

Linux

Make the AppImage runnable, then open it:
chmod +x L_Platform*.AppImage

Questions

Is it free?

Yes. The app and the AI Explorers course are free for students.

How do I get an account?

Your school or teacher creates it. You can also join a class with a class code from your teacher inside the app.

Does it need the internet?

You need it to sign in and submit work. The AI course and running Python code work offline, and drafts sync later.

Which programming languages are supported?

Python, Java and C++ in the editor. Python can be run and tested inside the app; Java and C++ answers are checked by your teacher.

Is my data safe?

Each school's data is separated at the database level. Students only see their own work, and we never ask for personal details beyond what your school provides.
